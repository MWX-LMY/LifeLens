📋 项目概述

LifeLens 是一款基于 Electron 的桌面应用，每隔 20 秒自动截取屏幕截图，通过本地运行的 Qwen3-VL 多模态 AI 模型分析用户活动，生成结构化记录、10 分钟汇总、每日日记及多维度可视化看板。所有数据存储在本地，不上传云端。

⚙️ 技术栈

Electron Qwen3-VL 8B Node.js PowerShell

前端：HTML + CSS + JavaScript + Canvas 2D
后端：Electron 主进程 + Ollama REST API
打包：electron-builder NSIS

💾 数据流

截图 → AI 分析 → 每小时 JSON 日志
→ 10分钟汇总 → 每日日记 → 看板统计

数据目录：%APPDATA%/LifeLens/data/

📦 五大模块

📊 仪表板

实时状态面板。显示运行状态、截图计数、分析队列。右侧时间线展示每次 AI 分析的结果，自动滚动，支持展开/收起长文本。

📋 动态

GitHub 风格热力图展示 10 分钟活动块，颜色区分活动类型。纵向时间线展示汇总详情，可按项目/软件/分类筛选。

📖 日记

所有日记以卡片网格展示（每行 3 列）。每张卡片包含日期、摘要、主要事项、高光、待办、优化建议和温馨提示。可按周筛选。

📈 看板

活动类型饼图、软件使用排名、项目专注排名。支持全部/年/月/周/日时间范围切换。Canvas 2D 绘制，12 色炫彩方案。

💬 问答

Agentic 搜索 + 流式回答。模型自主决定搜索关键词、时间范围和数数据源，最多 3 轮迭代。结果不足时自动返回最近记录。

🔧 问题处理记录

截图组件不兼容 Windows 11 FIXED
screenshot-desktop npm 包无法调用 .NET 编译器编译截图工具。改用 PowerShell 原生调用 System.Windows.Forms API 截图，无需第三方依赖。
Ollama 分析超时 FIXED
初始 60s 超时不够，分析频繁中断。图片分析超时调整至 180s，文本汇总 45s。发送前将图片从 1920px 缩小至 800px JPEG，减少 90% 传输量。
UI 标签页内容高度为 0 FIXED
display:block !important 覆盖 flex 布局，flex-basis:0% 使高度坍缩。移除 !important，统一使用 flex 布局。同时发现 HTML 嵌套错误（日记/问答标签页嵌套在活动标签页内部），补充缺失闭合标签修复。
问答搜索空结果 FIXED
模型在第一次迭代就设置 stop:true，未搜索直接回答"0 条记录"。强制至少搜索一次，无匹配时自动返回最近 5 条汇总。
"汇总中"状态卡死 FIXED
sendSummaries() 在删除汇总状态前调用，渲染器一直显示"汇总中"。将通知移到 finally 块，确保状态清除后通知渲染器。
日记不更新 FIXED
日记缓存后即使有更多汇总数据也不重新生成。添加汇总数比较逻辑，新汇总多于日记记录数时自动重新生成。
打包后无法写入数据 FIXED
Electron 打包后 __dirname 指向只读 app.asar。使用 app.getPath('userData') 获取 %APPDATA%/LifeLens/data 可写目录。
