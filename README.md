# 🔵 LifeLens — AI 活动记录仪

> 本地 AI 自动记录你的一天：每 20 秒截屏 → Qwen3-VL 看图分析 → 10 分钟汇总 → 每日日记 → 可视化看板 → 随时提问。
> 所有数据只存在你自己的电脑上，不上传任何云端。

![LifeLens](icon.png)

---

## 1. 项目解决什么问题

**问题：** 一天坐在电脑前十几个小时，回头却说不清时间花在了哪里——哪些项目占了多久、哪些软件用得多、哪些时段最专注。

**LifeLens 的做法：** 像行车记录仪一样持续记录屏幕活动，但记录的不是画面本身，而是**本地 AI 理解的"你在做什么"**：

- 每隔 **20 秒** 自动截取一次屏幕；
- 本地 Ollama 运行多模态模型（默认 `qwen3-vl:8b`），把截图翻译成 5 句中文活动描述；
- 每 **10 分钟** 把零散描述汇总成一条结构化记录（项目、分类、软件、待办）；
- 每天自动生成一篇**日记**；
- 所有记录支持**搜索问答**——"我昨天下午在做什么？" 直接问 AI。

**隐私说明：** 截图和分析全部在本机完成，模型本地运行，无任何数据上传。截图仅保留 3 天，每 6 小时自动清理。

## 2. 主要功能

### 📸 自动截图（每 20 秒）
- PowerShell 调用 .NET `System.Windows.Forms` 全屏截图，Windows 10/11 原生可用，零第三方截图依赖；
- PNG 原图落盘，发送给 AI 前自动缩小到 800px 宽 JPEG（75% 质量）以加速分析。

### 🤖 AI 活动分析
- 调用本地 Ollama API，默认模型 `qwen3-vl:8b`，可在设置中切换任意已安装模型；
- 每张截图输出 5 句中文活动描述（软件/网站、具体操作、任务类型、屏幕细节、状态判断）；
- 图片分析超时 180s，失败自动降级为"（AI分析失败）"并继续下一轮，不中断流程。

### 🕙 10 分钟汇总引擎
- 每 30 秒检查一次可汇总的时间块（块结束 30 秒后、至少 2 条记录才触发，最多同时汇总 2 块）；
- 汇总输出：项目名、分类（工作/娱乐/学习/社交）、简要描述、软件列表、待办；
- 项目名称自动延续上一个时段，保持连贯。

### 📖 每日日记（二阶 AI 汇总）
- 基于当天全部 10 分钟汇总自动生成结构化日记：50 字总结、Top 3 事项、高光时刻、待办、优化建议、一句话提示；
- 当天有新汇总时自动重新生成；启动后自动补全缺失的日记。

### 📊 仪表板
- 运行状态呼吸灯、开始/停止捕获按钮、分析队列计数；
- 今日截图数、已分析数、实时活动时间线（带活动类型标签，长文本可展开）。

### 📋 动态（时间线 + 热力图）
- 活动热力图：每个格子 = 一个 10 分钟块，颜色深浅表示活跃程度，点击可定位到对应时间线卡片；
- 按**项目名 / 软件名 / 分类**三重筛选，查看任意时段的活动记录。

### 📈 看板（Canvas 2D 图表）
- 饼图：活动类型（工作/娱乐/学习/社交）占比；
- 柱状图：软件使用排行、项目专注排行（各 Top 15）；
- 时间范围：年 / 月 / 周 / 日，并可精确选择某一年/月/周/日。

### 💬 AI 问答（Agentic 搜索）
- 最多 3 轮自主搜索规划：模型自己决定关键词、时间范围和数据源（10 分钟汇总 / 20 秒快照 / 每日日记）；
- 至少执行一次真实搜索，结果不足时回退最近 5 条汇总作为上下文；
- 流式 Token 输出实时显示；问答期间自动暂停截图分析，结束后恢复。

### 🖥️ 系统托盘与后台运行
- 关闭窗口**不退出**，最小化到托盘继续记录；
- 托盘菜单：暂停/恢复捕获、显示窗口、退出；双击托盘图标唤出窗口。

### ⚙️ 模型设置
- 标题栏齿轮 → 设置面板：一键刷新检测 Ollama 已安装模型，下拉选择，保存立即生效，无需重启。

### 🧹 数据管理
- 截图超过 **3 天自动删除**（每 6 小时清理一次，启动后也会执行一次），并清理空目录。

## 3. 安装方法

### 3.1 环境要求

| 组件 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 64 位（截图依赖 PowerShell + .NET） |
| Ollama | 必须安装并保持运行（`ollama.com` 下载） |
| 多模态模型 | 推荐 `qwen3-vl:8b`（8GB 显存）；低配可选 `qwen3-vl:7b` / `4b` / `2b` |
| 硬件 | NVIDIA 8GB+ 显存（GPU 加速）；无独显可用 CPU 跑小模型 |
| Node.js | 仅从源码运行时需要（18+） |

### 3.2 安装 Ollama 并拉取模型

```bash
# 1. 安装 Ollama：https://ollama.com/download（Windows 版）
# 2. 拉取视觉模型（三选一，按配置）
ollama pull qwen3-vl:8b   # 推荐：GPU 8GB 显存
ollama pull qwen3-vl:7b   # CPU 首选
ollama pull qwen3-vl:4b   # 低配置

# 3. 验证
ollama list
```

### 3.3 方式一：安装包（推荐给最终用户）

```bash
# 在项目目录构建 Windows 安装包（NSIS）
npm run dist
# 产物：dist/LifeLens-Setup-0.1.0.exe
```

- 双击安装包安装（可选安装目录，创建桌面/开始菜单快捷方式）；
- 已构建的免安装版可直接运行：`dist/win-unpacked/LifeLens.exe`。

### 3.4 方式二：从源码运行（开发）

```bash
npm install      # 国内网络可先配置 electron 镜像：ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm start        # 启动（等价 electron .）
npm run dev      # 开发模式启动（electron . --dev）
```

> 构建配置（electron-builder）见 `package.json` 的 `build` 字段。

### 3.5 数据目录

首次启动自动创建，位置为**应用所在目录下的 `LifeLens_Data\`**（开发模式在项目目录下）：

```
LifeLens_Data/
├── config.json              # 设置（模型、上下文长度）
├── summaries.json           # 10 分钟汇总
├── diaries.json             # 每日日记
└── 2026-10/                 # 按月分目录
    ├── screenshots/         # 截图（保留 3 天）
    └── 2026-10-20_19.json   # 每小时分析日志
```

## 4. 使用方法

### 4.1 启动

双击桌面 **LifeLens** 图标。启动后**自动开始**截图与分析，无需任何操作；标题栏显示"● 运行中"。

### 4.2 五个标签页

| 标签 | 用途 |
|------|------|
| 📊 仪表板 | 查看运行状态、计数与实时活动时间线；按钮可停止/开始捕获 |
| 📋 动态 | 热力图 + 汇总时间线，按项目/软件/分类筛选 |
| 📖 日记 | 浏览自动生成的每日日记卡片 |
| 📈 看板 | 活动类型饼图、软件/项目柱状图，切换年/月/周/日 |
| 💬 问答 | 用自然语言查询自己的活动记录 |

### 4.3 常用操作

- **暂停/恢复记录**：仪表板左侧按钮，或托盘图标右键菜单；
- **切换模型**：标题栏 ⚙️ → 刷新 → 选择模型 → 保存（立即生效）；
- **后台运行**：点 ✕ 只隐藏窗口，记录不中断；托盘右键 → 退出 才真正退出；
- **清理数据**：截图自动清理（3 天），无需手动操作。

### 4.4 时间说明

- 截图间隔 20 秒 → 每分钟最多 3 条快照记录；
- 10 分钟块结束后约 30 秒生成汇总；
- 当天日记随汇总进度自动生成/更新；
- 截图按时间命名：`YYYY-MM-DD_HH-MM-SS.png`。

## 附：技术栈与项目结构

- **技术栈：** Electron 33 + Node.js + HTML/CSS/JS + Canvas 2D + PowerShell（截图）+ Ollama API
- **关键超时：** 图片分析 180s / 汇总 45s / 日记 45s / 问答规划 30s / 问答回答 120s
- **进程模型：** 主进程负责截图、AI 调用、汇总、日记、统计与清理；渲染进程通过 preload 暴露的 IPC 桥接通信（contextIsolation 开启）

```
LifeLens/
├── main.js              # 主进程：截图、分析、汇总、日记、统计、问答、托盘、清理
├── preload.js           # IPC 桥接（window.lifelens API）
├── index.html           # UI 界面（5 个标签页 + 设置弹窗）
├── renderer.js          # 渲染逻辑：时间线、热力图、Canvas 图表、问答流式显示
├── package.json         # 项目配置 + electron-builder 构建配置
├── icon.png / icon.ico  # 应用图标
├── bg.png               # 背景图
├── dist/                # 构建输出（LifeLens-Setup-*.exe / win-unpacked）
└── LifeLens_Data/       # 运行时数据（自动生成，见 3.5）
```
